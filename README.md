## 🌟 Executive Summary & Problem Statement

Modern educational platforms frequently suffer from three fundamental bottlenecks:
1. **The Digital Divide**: Millions of students in rural or low-connectivity zones lack high-speed broadband or high-end smartphones, locking them out of contemporary EdTech.
2. **Passive Rote Learning**: Static textbook diagrams and 2D textbook pages fail to convey physical intuition, dynamic vectors, and experimental causality.
3. **Unverified Credentials**: Traditional online certificates are easily forged and lack cryptographic proof of authentic hands-on laboratory mastery.

**NEXUS LEARN** resolves these challenges through a unified, hyper-accessible platform combining **AI-driven voice telecommunications (WebRTC/SIP)**, **multimodal diagram-to-simulation generation**, and **W3C Open Badges 3.0 on-chain credentials**.

## 🚀 Key Breakthrough Innovations

### 1. 🔬 Multimodal Snap-and-Simulate (Vision-to-3D AR/VR Lab) — `/virtuallab/snap`
- **Textbook Photo Decomposer**: Point your phone camera or upload any textbook diagram (e.g. Kinematics, Circuits, Optics, Pulleys).
- **Gemini Multimodal Vision Engine**: Analyzes topology, forces, and equations to instantly spawn an interactive 60 FPS 3D canvas physics laboratory.
- **Dynamic 1D Kinematics & Vertical Motion**:
  - Simulates instantaneous flight: $y(t) = v_0 t - \frac{1}{2}gt^2$, $v(t) = v_0 - gt$, and $a(t) = -g$.
  - Dynamic **Velocity Vector ($\vec{v}$)** and constant **Gravitational Acceleration Vector ($\vec{a} = -9.8\text{ m/s}^2$)**.
  - Apex Rest Badge: Lights up when ball reaches maximum altitude ($v = 0\text{ m/s}$ instantaneously at rest).
  - Inset real-time dual graphs for $y(t)$ position curve and $a(t)$ acceleration.
- **Full Suite of Interactive Experiments**:
  - 🚀 1D Kinematics & Vertical Projectile Throw
  - ⚡ Wheatstone Bridge Circuit with Galvanometer Null Deflection
  - 🔍 Double Convex Lens Optical Bench with Gaussian Ray Tracing
  - ⚖️ Atwood Coupled Pulley Dual-Mass Accelerator
  - ⏱️ Simple Harmonic Pendulum with Conservation of Mechanical Energy

### 2. 🥽 WebXR Study Desk Augmented Reality — `/virtuallab/ar`
- Project interactive 3D physics, chemistry, and biology experiments directly onto your physical desk using mobile browser camera pass-through and WebXR APIs.
- Zero extra hardware or expensive headsets required.

### 3. 📞 Ultra-Low-Latency Full-Duplex AI Dial-In Phone Tutor — `/dial-in`
- **Zero-Data / Feature Phone Ready**: Students without internet dial toll-free **1800-891-LEARN** from basic feature phones (e.g., JioPhone).
- **Interactive DTMF Keypad**: Press 1 for Physics, 2 for Chemistry, 3 for Mathematics, 4 for Biology, 5 for Computer Science.
- **Synchronized Live Diagrammatic Whiteboard**:
  - As the Socratic AI speaks over the call, a synchronized visual whiteboard renders high-contrast SVG scientific diagrams in real time.
  - **100% Diagrammatic Guarantee**: Every question asked—across calculus, mechanics, optics, thermodynamics, or algorithms—is accompanied by a labeled technical diagram.
- **Multilingual Socratic Dialogue**: Natural conversational voice tutoring in English, Hindi (हिंदी), and Tamil (தமிழ்).

### 4. 💬 Omni-Sync WhatsApp Micro-LMS — `/whatsapp-lms`
- Lightweight conversational alternative to heavy LMS apps.
- Delivers concise audio notes, symbolic polynomial calculus solutions ($dy/dx$), and live formula diagrams via WhatsApp messaging.
- Daily 2-minute syllabus drill quizzes with instant grading and explanations.

### 5. 🏆 Verifiable Proof-of-Skill On-Chain Badging & LinkedIn Integration — `/credentials`
- **W3C Verifiable Credentials (VC) & 1EdTech Open Badges 3.0**: Tamper-proof, cryptographically signed academic credentials (Ed25519 signatures).
- **3D Medallion Badges**: Beautiful metallic tier badges (Gold, Platinum, Diamond, Master, Elite) with laurel wreaths and star ratings.
- **Official 1-Click LinkedIn Add-to-Profile Integration**:
  - Direct deep linking with pre-filled certification name, issuing organization (*NEXUS LEARN*), issue date, and verifiable URL.
- **Downloadable Badge Assets**: Export high-resolution vector `.SVG` badges for personal portfolios and GitHub READMEs.
- **W3C JSON-LD Proof Inspector**: View and copy full cryptographic JSON-LD DID payloads.

### 6. 📡 Offline Village Mesh Network — `/mesh`
- P2P offline learning resource synchronization for low-connectivity rural schools using WebRTC data channels and local browser storage.

### 7. 🐛 Adversarial Reverse Bug Hunter — `/code/reverse-debug`
- Hands-on coding studio where students debug deliberately mutated code, identify logic errors, and strengthen algorithmic problem-solving.

### 8. ⚔️ RPG Quest Engine & Co-Op Study Battles — `/rpg` & `/rpg-multiplayer`
- Gamified learning curriculum with quest trees, boss battles, XP, level progression, and real-time multiplayer study battles.

### 9. 🌌 3D Knowledge Universe Navigator — `/universe`
- Interactive 3D celestial galaxy mapping curriculum prerequisites, concept mastery stars, and personalized knowledge graphs.

### 10. 🧬 Cognitive Digital Learning Twin — `/twin`
- Models student retention using Ebbinghaus forgetting curve algorithms to deliver timely spaced-repetition prompts.

### 11. 🧑‍🏫 Institutional Teacher Portal & Syllabus Sync — `/teacher`
- Generates 6-character syllabus codes for teachers to push curricula, monitor classroom weak spots, and trigger adaptive mock tests.

## ⚡ Quick Start & Local Setup

### Prerequisites
- [Node.js](https://nodejs.org/) v18.18+ or v20+
- `npm` or `pnpm`
- (Optional) Google Gemini API Key from [Google AI Studio](https://aistudio.google.com/)

### 1. Clone the Repository
```bash
git clone https://github.com/hemalathabe2526-hub/SIH_Nexus-learn-App.git
cd SIH_Nexus-learn-App
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env.local` file in the project root:
```env
GEMINI_API_KEY=your_gemini_api_key_here
NEXT_PUBLIC_APP_URL=http://localhost:3000
```
*(Note: If no Gemini API key is provided, the platform automatically switches to its high-fidelity procedural STEM solvers and offline fallback engines.)*

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Production Build
```bash
npm run build
npm run start
```

## 🛡️ Security, Privacy & Permissions

NEXUS LEARN implements an explicit **3-tier device permission model** for all camera, microphone, and WebXR features:
1. **Allow while using this app**: Grants permission for the ongoing session.
2. **Allow only this time**: One-shot permission revoked on component unmount.
3. **Block**: Permanently restricts device access; seamlessly switches to manual file uploads and keypad interactions.
- All stored choices can be reviewed and reset with a single click from the UI header.
